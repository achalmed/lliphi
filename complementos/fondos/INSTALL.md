## Instalar a mano

```bash
cp -r org.lliphi.horizonte ~/.local/share/wallpapers/
plasma-apply-wallpaperimage ~/.local/share/wallpapers/org.lliphi.horizonte
```

Plasma elige `images_dark/` cuando el esquema de color es oscuro (Plasma ≥ 6.6); en versiones anteriores usa siempre la imagen clara. En Plasma 6.6 el paquete se aplica **por ruta**, no por nombre.

## Actualizar

Sustituye la carpeta y vuelve a aplicarla.

## Desinstalar

Elige otro fondo (clic derecho en el escritorio → Configurar escritorio y fondo) y borra `~/.local/share/wallpapers/org.lliphi.horizonte`.
