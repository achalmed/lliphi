# Lliphi para VS Code

Tema para KDE Plasma: casi negro y gris suave con un acento rojo; mínimo, legible y reversible.

Dos temas, **Lliphi Oscuro** y **Lliphi Claro**, generados desde los tokens
de Lliphi (los mismos del escritorio Plasma y de las terminales): la interfaz sigue el esquema de color,
la sintaxis los dieciséis ANSI y la terminal integrada el esquema de Konsole.

Generado por `herramientas/generar.py`; no editar. Sitio: https://achalmed.github.io/lliphi/ · Código: https://github.com/achalmed/lliphi
